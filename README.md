# LleidArena – Web del curs anterior

## Descripció
LleidArena és una pàgina web dedicada a un festival de música a Lleida. Inclou informació sobre les dates, la programació, els patrocinadors, les preguntes freqüents, el contacte i el registre.

## Tecnologies utilitzades
- HTML5 per a l'estructura de la pàgina.
- CSS3 per al disseny i l'estil visual.
- Firebase Hosting per publicar la web a Internet.

## Com executar la web localment
1. Descarregar o clonar aquest repositori.
2. Obrir la carpeta `public`.
3. Obrir el fitxer `index.html` amb un navegador web o utilitzar Live Server des de Visual Studio Code.
